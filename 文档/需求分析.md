## 1. 项目背景与目标

### 1.1 背景

2048 和数字华容道都是规则简单、适合触屏操作、容易在碎片时间游玩的经典益智游戏。课程要求完成一个可运行、可演示的移动端应用，并在完成基础功能之外体现一定的工程能力与云端能力。

项目最初完成 2048，随后在同一小程序内扩展数字华容道，并接入微信云开发，形成“小游戏合集”：既保留单机可玩的稳定性，又通过云端排行榜和每日挑战增加用户留存与可演示性。

### 1.2 目标

1. 实现完整、规则正确的 2048；
2. 实现 3×3 / 4×4 数字华容道，支持可解打乱、计时、步数与最佳记录；
3. 设计统一首页，在 2048 与华容道之间切换；
4. 接入微信云开发：登录、云端最佳记录、总榜/周榜、每日挑战；
5. 保证无云环境时自动降级为单机模式；
6. 提供可测试、可维护的代码结构，并完成测试、截图与部署。

### 1.3 范围

**本期包含**

- 微信小程序端（WXML / WXSS / JavaScript）；
- 微信云开发云函数与云数据库；
- 2048、数字华容道 3×3/4×4；
- 首页、排行榜、每日挑战、昵称与主题；
- 单元测试、静态检查、模拟器验证、部署文档。

**本期不包含**

- 公开发布与审核；
- 付费服务器、独立域名、短信/支付；
- 多人实时对战；
- 跨账号数据迁移；
- 2048 的服务端完整重放防作弊（本期做范围校验，华容道做完整重放）。

## 2. 用户与使用场景

### 2.1 目标用户

- 课程教师：检查功能完整性、技术深度、工程质量与演示效果；
- 同学/体验成员：扫码体验，查看排行榜、挑战每日关卡；
- 项目组：维护源码、部署云函数、更新版本。

### 2.2 典型场景

| 场景 | 用户行为 | 系统响应 |
| --- | --- | --- |
| 首次进入 | 打开小程序 | 显示首页、静默登录、显示昵称/云端状态 |
| 玩 2048 | 首页点 2048，滑动棋盘 | 合并/计分/生成数字，结束或胜利后上传成绩 |
| 玩华容道 | 首页点华容道，选 3×3/4×4，滑动 | 移动数字、计时、步数、完成弹窗、上传成绩 |
| 每日挑战 | 首页点每日挑战 | 使用服务端当天的固定 3×3 棋盘，完成计入最佳 |
| 看排名 | 首页点排行榜 | 切换游戏/周期，查看前 50 名与我的排名 |
| 改昵称 | 首页云端卡点修改昵称 | 校验 2–12 字符，更新玩家与排行榜昵称 |
| 网络/云异常 | 断网或云环境失效 | 排行榜提示错误；游戏仍可单机玩 |
| 换游戏 | 子页面点“‹ 游戏合集” | 有进度时确认，返回首页重新选择 |

## 5. 关键用例

### UC-01 完成一局数字华容道并上榜

1. 用户从首页进入“数字华容道”，选择 3×3；
2. 系统生成可解棋盘并开始计时；
3. 用户滑动移动数字，系统累计步数；
4. 棋盘完成，系统停止计时、保存本地最佳；
5. 客户端提交 seed/directions/time 到云函数；
6. 云函数重放验证，更新 `rankings` 与 `players`；
7. 弹窗显示“成绩已上传云端/最佳已更新”。

**异常**：云调用失败 → 提示“成绩仅保存在本机”；每日日期变化 → 拒绝并提示重新进入。

### UC-02 查看今日挑战榜

1. 用户进入排行榜，选择“华容道 3×3 → 今日挑战”；
2. 客户端调用云函数查询 `rankings` 的 `daily:YYYY-MM-DD`；
3. 云函数排序后返回前 50 名与我的排名；
4. 页面高亮当前用户；无数据时显示空榜提示。

### UC-03 云环境不可用

1. 首页登录失败 → 显示“单机模式”；
2. 每日挑战使用本地种子，仍可玩；
3. 排行榜显示“云开发环境未配置/网络异常”与重试；
4. 游戏结束不阻塞，成绩保存在本机。

## 6. 验收标准

- 2048 合并、计分、胜负、重开全部正确；
- 华容道 3×3/4×4 可完成，打乱有解，滑动方向符合直觉；
- 首页、排行榜、每日挑战、昵称可用；
- 云函数可部署，登录/提交/排行榜真实可用；
- 无云环境降级正常；
- 103 个单测、9 项静态检查通过；
- 至少 21 张真实截图，README/需求/设计/成绩评定表齐全；
- 真机体验版可扫码运行（由教师/组员验收）。

## 7. 约束与风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 云开发免费体验到期/收费 | 排行榜不可用 | 文档提示到期前停用；无云自动降级；课程演示期保持有效 |
| 云函数冷启动 | 首次登录/每日挑战慢 | 页面 loading/轮询；失败降级本地 |
| 小程序 AppID 类型错误 | 无法编译 | 必须使用“小程序”账号，不用“小游戏” |
| 每日挑战被篡改 | 排名不公 | 服务端日期/种子 + 完整重放校验 |
| 2048 仅范围校验 | 极端作弊可能 | 课程项目接受；后续可增加服务端重放 |
| 云数据库查询上限 | 用户量大时榜单不全 | 当前取 100 条排序返回 50；后续分页/索引 |
