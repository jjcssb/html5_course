## 8. 测试过程中发现并修复的问题

1. **工具栏主题切换被挤扁**：固定工具栏按钮宽度、主题切换 `flex:1 1 0` + `min-width:0`。
2. **深色导航栏仍是白色**：增加 `onShow` 再次同步导航栏颜色。
3. **预览包 1.0 MB**：补充 `packOptions.ignore`，恢复到 100–135 KB 级别。
4. **华容道路由少写 `/index`**：`/pages/klotski/game?size=` → `/pages/klotski/game/index?size=`。
5. **华容道切后台后计时不恢复**：`onHide` 停止计时，`onShow` 按 `startedAt` 恢复。
6. **缺少切换游戏入口**：子页面增加“‹ 游戏合集”，有进度时确认。
7. **云函数部署缺少 `lib/` 子目录**：线上报 `Cannot find module './lib/verify'`；把 `klotski.js / random.js / verify.js` 移到云函数根目录并改 require，重新部署成功。
8. **CloudBase 更新 null 嵌套对象失败**：`Cannot create field 'at' in element {best3: null}`；最佳记录改为扁平字段 `best3Moves / best3Time / best3At` 等，部署后通过。
9. **云函数冷启动导致登录偶发慢**：在线测试增加轮询等待（最多 10 秒），不修改业务逻辑。
10. **自动化工具限制**：`page.callMethod` 不兼容（改用 `evaluate`）；截图每页只能一次（逐场景进程）；`navigateBack/redirectTo/reLaunch` 在自动化上下文不生效（测试改用 `navigateTo`，真实用户不受影响）。
11. **每日挑战排名显示偏差**：提交后按总榜计算、且统计包含自己的旧记录，弹窗显示“第 2 名”而今日榜显示“第 1 名”；改为按 `daily:日期` 计算，并在排名统计中排除自己的旧记录，弹窗区分“今日榜/总榜”；重新部署云函数并上传 v1.8.0。
12. **华容道用时显示 00:00（用户实测反馈）**：自动化截图/测试瞬间完成，写入了 0 秒测试成绩；排行榜只保留更优成绩，导致真实成绩无法覆盖 0 秒记录。修复：清理云端测试榜单与测试玩家；云函数拒绝 `timeMs < 1000`；客户端本地忽略 `timeMs <= 0` 的旧记录；重新上传 v1.8.0。真实等待 2.6 秒的计时验证得到 `timeMs=2624`，计时器本身正常。
13. **从游戏返回首页成就数不刷新**：首页 `onShow` 只刷新主题，未重新读取本地缓存的 player；改为 `onShow` 时用 `applyPlayer` 同步成就/昵称，或重新登录；重新上传 v1.8.0。
14. **体验版二维码直达 2048，不进主页**：入口路径带 `pages/index/index`，注册后再次扫码仍落 2048；增加入口纠正：页面栈只有 2048 且无 `daily/resume/share/standalone` 参数时 `reLaunch` 首页；从首页点 2048 才进入游戏。实测：直接 2048 → 首页/建档；首页点 2048 → 2048。重新上传 v1.8.0。
15. **最佳成绩不更新/时间被 35 秒卡住**：旧记录存在 `moves=0 + time=35000`，按“步数优先”比较时新成绩永远输给 0 步；同时自动化测试在真实账号里反复写入测试成绩。修复：`isBetter`/`isBetterRecord` 把 `moves<=0` 视为无记录；`submitRun` 后把 `result.best` 写回本地 player；新增 `resetMyScores` 清除测试成绩（保留昵称/头像/性别）；排行榜过滤 `moves<=0` 的旧行。v1.8.0。
16. **排行榜默认打开今日挑战**：默认改为**总榜**；移除今日挑战排行榜入口，排行榜只保留总榜/本周；每日挑战保留玩法，完成计入最佳。
17. **头像太单一**：新增 `open-type="chooseAvatar"`，选择微信头像后上传云存储，保存 `avatarUrl`；首页、资料页、排行榜都显示自定义头像。保留 6 个内置头像作为备选。
